# Documentation AquaMeasure

Trois documents de référence :

- Manuel utilisateur : [en ligne](MANUEL_UTILISATEUR.md), [PDF](pdf/AquaMeasure_Manuel_Utilisateur.pdf), [Word](word/AquaMeasure_Manuel_Utilisateur.docx). Synchroniser, calibrer, mesurer, suivre et placer les marqueurs.
- Manuel des modèles IA : [en ligne](DETECTEURS.md), [PDF](pdf/AquaMeasure_Guide_Extension_Modeles_Detection.pdf), [Word](word/AquaMeasure_Guide_Extension_Modeles_Detection.docx). Charger et mettre à jour les modèles ; enrichir et transférer la bibliothèque Fishial.
- [Guide du code](GUIDE_DEVELOPPEUR.md) : architecture, calculs, données, tests et compilation. Ce document reste en Markdown pour GitHub.

Le dossier **word** contient uniquement les deux manuels. `MANUEL_UTILISATEUR.md` et `DETECTEURS.md` sont leurs sources ; `build_word.py` régénère ces deux Word.

Seule la documentation courante est publiée dans ce dépôt.

Les captures ont été refaites le **8 septembre 2026** dans l'interface actuelle. Les tutoriels distinguent les comportements ponctuels, les comportements sur une durée et la trajectoire avec ses points facultatifs. Les exemples utilisent les vidéos du bassin et une copie isolée de la session de démonstration ; longueurs, espèces fictives et marqueurs illustrent les commandes.
